# 🌐 Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, experience, and projects as a frontend developer. Built using **HTML**, **CSS**, and **JavaScript** to ensure a clean and responsive design.

## 🔗 Live Demo

[View Portfolio](https://its-my-first-portfolio.netlify.app/)

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure of the pages  
- **CSS3** – Styling and layout (Flexbox/Grid, media queries)  
- **JavaScript** – Interactive features and dynamic content  
- *(Optional)* **ScrollReveal / GSAP / Typed.js** – for animations and interactivity
